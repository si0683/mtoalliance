# МТО-Альянс — лендинг

Сайт компании «МТО-Альянс» (MTO ALLIANCE): поставки нефтегазового оборудования,
рефрижераторных контейнеров и вагонов. Построен на [Astro](https://astro.build)
по структуре внутреннего шаблона `_template` — **без Tailwind**: чистый семантический
HTML, стили — в scoped `<style>` каждого компонента, общие токены и примитивы — в `src/styles/global.css`.

## 🚀 Структура проекта

```text
/
├── public/                 # статика «как есть» (favicon, логотип, картинки, PHP-обработчик формы)
│   ├── assets/img/          # фотографии и карта
│   ├── libs/PHPMailer/      # библиотека отправки писем для send.php
│   └── send.php             # серверный обработчик формы (нужен PHP-хостинг)
├── src
│   ├── components/          # секции страницы (Header, Hero, Stats, …, Footer) со scoped-стилями
│   ├── layouts/             # обёртка страницы (Layout.astro — <html>/<head>)
│   ├── pages/               # маршруты (index.astro — главная)
│   ├── scripts/             # клиентский JS (интерактив, карта, форма)
│   └── styles/              # global.css: токены :root + общие классы (.wrap, .btn, .tag, .section, .reveal)
└── package.json
```

## 🧞 Команды

Все команды выполняются из корня проекта:

| Команда             | Действие                                         |
| :------------------ | :----------------------------------------------- |
| `npm install`       | Установка зависимостей                           |
| `npm run dev`       | Локальный dev-сервер на `localhost:4321`         |
| `npm run build`     | Сборка продакшн-версии в `./dist/`               |
| `npm run preview`   | Просмотр собранной версии перед деплоем          |

## 🎨 Как организованы стили

- **`src/styles/global.css`** — токены палитры (`:root`), базовый сброс и разделяемые между
  секциями классы: `.wrap`, `.btn*`, `.tag`, `.section*`, `.lead`, `.reveal`, `.brand__logo`.
- **Компоненты** — каждая секция держит свои стили в собственном `<style>` (Astro scoped).
- Исключение — `Geo.astro` и `Contacts.astro`: часть их DOM (точки/маршруты карты, список файлов)
  создаётся из JS уже после сборки и не получает scoped-атрибут, поэтому их стили помечены
  `<style is:global>`.

## ✉️ Форма обратной связи

Отправка заявок работает в двух режимах (переключается в `src/scripts/main.js`, переменная `FORM_MODE`):

- `formsubmit` — сервис FormSubmit, работает на статике (в т.ч. GitHub Pages);
- `php` — свой обработчик `public/send.php` на PHPMailer (нужен PHP-хостинг).

> ⚠️ Astro dev/preview не исполняет `send.php`. Для PHP-режима нужен реальный PHP-хостинг:
> после `npm run build` содержимое `dist/` (со скопированными `send.php` и `libs/`) выкладывается в корень сайта.
